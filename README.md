# EgoDecade

**A Decade-Scale Egocentric Video Dataset**

## Overview

EgoDecade is a longitudinal egocentric video dataset spanning approximately ten years of real-world experiences recorded by a single participant.

The project focuses on the curation and organization of long-term first-person video recordings to support research in egocentric vision, long-horizon video understanding, and embodied intelligence.

EgoDecade is a research initiative led by **Action Intelligence**. The project is currently in the data organization, curation, and infrastructure preparation phase.

## Dataset Overview

| Attribute | Description |
|---|---|
| Number of Participant | Only one person |
| Temporal Coverage | Approximately 10 years |
| Planned Data Volume | Up to 800 TB |
| Primary Modality | First-person RGB video |
| Data Characteristics | Longitudinal real-world recordings |
| Data Organization | Time-based and activity-based organization |
| Release Strategy | Progressive release of curated subsets |

Detailed dataset structures, annotations, and internal processing specifications are not publicly disclosed at this stage.

## Data Governance

Data collection and publication authorization from the data contributor have been confirmed.

All publicly released data will undergo appropriate curation and privacy review. Sensitive visual information and third-party personal information will be reviewed and anonymized where necessary.

Only approved and privacy-reviewed subsets will be made publicly available.

## Infrastructure and Release Plan

The project is preparing a scalable cloud storage and data management infrastructure, with AWS S3 as a target platform for dataset storage and access.

The planned release schedule is:

- **Current Phase:** Data organization, curation, and infrastructure preparation.
- **Q2 2027:** Initial release of a selected subset of curated and privacy-reviewed videos.
- **Subsequent Phases:** Progressive expansion of the dataset following additional curation and review.

The complete dataset will be made available through the project's designated access arrangements as the relevant preparation and review processes are completed.

## Collaboration

The project involves academic collaboration between Nanjing University (NJU) and Nanyang Technological University (NTU).
